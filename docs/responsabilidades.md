## Matriz de Responsabilidades (RACI) — Obra Prima

Equipe (colunas): Diretoria / Gestão | Engenharia / Coordenação | Orçamento / Planejamento | Suprimentos / Compras | Financeiro / Administrativo | Mestre de Obras / Produção | Cliente / Incorporadora | Comercial / Relacionamento

Legenda: R = Responsável (execução); A = Aprovador final; C = Consultado; I = Informado

### Matrizes por processo

- **Cadastro (clientes, obras, fornecedores)**
  - R: Orçamento / Planejamento
  - A: Diretoria / Gestão
  - C: Engenharia, Comercial
  - I: Financeiro, Produção, Cliente

- **Planejamento físico‑financeiro**
  - R: Orçamento / Planejamento
  - A: Diretoria / Gestão
  - C: Engenharia, Financeiro
  - I: Produção, Comercial, Cliente

- **Orçamento da obra**
  - R: Orçamento / Planejamento
  - A: Diretoria / Gestão
  - C: Engenharia, Comercial
  - I: Suprimentos, Financeiro, Produção, Cliente

- **Curva ABC / composição de custos**
  - R: Orçamento / Planejamento
  - A: Diretoria / Gestão
  - C: Suprimentos, Engenharia, Financeiro
  - I: Produção, Comercial, Cliente

- **Solicitação de compra (requisição interna)**
  - R: Produção (Mestre de Obras)
  - A: Engenharia / Coordenação (ou Orçamento)
  - C: Suprimentos, Orçamento, Financeiro
  - I: Diretoria, Comercial, Cliente (quando aplicável)

- **Cotação de fornecedores**
  - R: Suprimentos / Compras
  - A: Suprimentos ou Orçamento (segundo política)
  - C: Engenharia, Orçamento, Produção
  - I: Financeiro, Diretoria, Comercial

- **Mapa de cotação / comparação**
  - R: Suprimentos
  - A: Orçamento / Planejamento
  - C: Engenharia, Financeiro
  - I: Diretoria, Produção, Comercial

- **Ordem de compra**
  - R: Suprimentos
  - A: Financeiro (liberação) / Diretoria para valores altos
  - C: Orçamento, Engenharia
  - I: Produção, Fornecedor, Cliente (se afetar prazo/escopo)

- **Recebimento de materiais (obra)**
  - R: Produção (Mestre de Obras)
  - A: Suprimentos (confirmação)
  - C: Financeiro, Engenharia
  - I: Diretoria, Comercial

- **Medições (avançamento / faturamento)**
  - R: Engenharia / Coordenação de obra
  - A: Orçamento / Planejamento (validação)
  - C: Produção, Financeiro
  - I: Cliente, Diretoria, Comercial

- **Contas a pagar**
  - R: Financeiro / Administrativo
  - A: Diretoria (ou gestor financeiro)
  - C: Suprimentos, Orçamento
  - I: Engenharia, Produção, Comercial

- **Contas a receber / faturamento**
  - R: Financeiro
  - A: Diretoria
  - C: Comercial, Orçamento (validação de medição)
  - I: Cliente, Engenharia, Produção

- **Fluxo de caixa**
  - R: Financeiro
  - A: Diretoria
  - C: Orçamento, Comercial
  - I: Engenharia, Produção, Suprimentos

- **Estoque de insumos**
  - R: Suprimentos (gestão operacional)
  - A: Orçamento / Planejamento (políticas)
  - C: Produção, Engenharia, Financeiro
  - I: Diretoria, Comercial

- **Relatórios gerenciais (KPIs, custos, progresso)**
  - R: Orçamento / Planejamento (consolidação)
  - A: Diretoria
  - C: Engenharia, Financeiro, Produção
  - I: Comercial, Cliente (quando aplicável)

- **Portal do cliente (documentos / contratos)**
  - R: Comercial / Relacionamento
  - A: Diretoria
  - C: Financeiro, Engenharia
  - I: Cliente, Produção

- **App móvel / apontamentos de campo**
  - R: Produção (Mestre de Obras)
  - A: Engenharia / Coordenação
  - C: Orçamento, Financeiro
  - I: Diretoria, Comercial, Cliente (quando visível)

---

Observações:
- Em empresas menores, combine papéis (R/A) em uma única pessoa quando apropriado.
- Defina faixas de aprovação por valor (ex.: até X → Gerente; acima → Diretoria).
- Posso gerar uma versão tabular (CSV/Excel) ou adaptar a matriz para diferentes estruturas organizacionais.

### Regras de aprovação por faixa de valor (exemplo)

As regras abaixo são um modelo sugerido. Posso ajustar os limites conforme sua política.

- Compras até R$ 5.000: Aprovador = Engenharia / Coordenação (A)
- Compras acima de R$ 5.000 e até R$ 50.000: Aprovador = Financeiro / Administrativo (A)
- Compras acima de R$ 50.000: Aprovador = Diretoria / Gestão (A)

Aplicação prática:
- Requisições iniciais são criadas pelo Mestre de Obras (R).
- Suprimentos executa a cotação e prepara mapa comparativo (C).
- Dependendo do valor, o aprovador será automático conforme faixa; compras estratégicas podem sempre subir para Diretoria.

Se quiser limites ou responsáveis diferentes (por cargo/região/tipo de compra), me diga as regras e atualizo o documento e o CSV/Excel.
